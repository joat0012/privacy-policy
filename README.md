# privacy-policy

Privacy policies for apps developed by [joat0012](https://github.com/joat0012), published via GitHub Pages.

Each app has its own subfolder:

- [`rove/`](rove/) — [Rove](https://github.com/joat0012/Rove)

## Publishing

GitHub Pages is served from the `main` branch, root folder (`/`).

- Site root: `https://joat0012.github.io/privacy-policy/`
- Rove: `https://joat0012.github.io/privacy-policy/rove/`

To add a new app, create a new subfolder with its own `index.html` and add a link on the top-level `index.html`.
