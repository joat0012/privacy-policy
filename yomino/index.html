Yomino プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-04

本ページは、アプリ「Yomino」(以下「本アプリ」)における個人情報・利用者情報の取り扱いについて説明するものです。 本アプリは、開発者(以下「開発者」)が個人で開発・提供しています。

1. 本アプリが取得する情報

本アプリは、PDFファイルの閲覧・注釈付けを行うアプリです。利用者がシステムのファイル選択画面で選んだPDF、または他のアプリから「共有」「アプリで開く」によって渡されたPDFのみを読み込みます。それ以外のファイルにアクセスすることはありません。

本アプリは、PDFを表示・管理するために、以下の情報を端末内にのみ保存します。

  • 書庫(最近開いたPDF・ピン留めしたPDF)の一覧:ファイル名、ファイルサイズ、ファイルの場所を示す情報、開いた日時など
  • しおり(ブックマーク)の情報
  • 他のアプリから共有されたPDFの複製、および表示を高速化するためのPDFの一時的な複製

ハイライト・手書き・付箋などの注釈やページの並べ替え・削除の結果は、利用者が保存を選んだときに、PDFファイル自体(元のファイル、または利用者が指定した保存先)に書き込まれます。

本アプリは、氏名・メールアドレス・位置情報・広告識別子など、利用者を特定できる情報を取得することはありません。PDFの内容や上記の情報が開発者や外部へ送信されることもありません。

2. 情報の保存場所・第三者提供の有無

本アプリはインターネット通信を一切行いません(インターネット接続の権限自体を持っていません)。広告SDK、アクセス解析(アナリティクス)SDK、クラッシュレポートSDK等も組み込んでいません。

そのため、本アプリで扱うPDFや書庫・しおりの情報が開発者のサーバー等の外部システムへ送信・アップロードされることはなく、開発者が利用者の情報を第三者に提供することもありません。

3. 利用する権限

本アプリは、カメラ・位置情報・連絡先・ストレージ全体へのアクセス等の権限を要求しません。PDFへのアクセスは、OSが提供するファイル選択画面や共有機能を通じて、利用者が選んだファイルに対してのみ許可されます。

書庫から同じPDFを再度開けるように、利用者がファイル選択画面で選んだPDFについては、OSが提供する仕組みによりそのファイルへのアクセス許可を保持します。この許可は、書庫から該当のPDFを削除すると解除されます。

4. データの削除

書庫からPDFを削除すると、そのPDFに関する書庫の情報、しおり、本アプリ内に保存された複製が削除されます(利用者自身の元のファイルは削除されません)。

本アプリをアンインストールすると、端末内に保存されたすべてのデータが削除されます(OSのバックアップ機能により端末のバックアップ内に複製が残る場合を除きます)。

5. 子供のプライバシーについて

本アプリは子供を主な対象としたアプリではなく、子供を含む利用者から個人情報を収集することはありません。

6. 本ポリシーの変更

本ポリシーの内容は、法令の変更やアプリの機能追加等に伴い、予告なく変更されることがあります。変更後の内容は本ページに掲載した時点で効力を生じるものとします。重要な変更がある場合は、本ページ上部の「最終更新日」を更新します。

This page explains how the app "Yomino" (the "App") handles personal information and user data. The App is developed and provided by an individual developer (the "Developer").

1. Information the App Collects

The App is a PDF viewer with annotation features. It reads only the PDFs you select in the system file picker, or that another app hands to it via "Share" or "Open with". It does not access any other files.

To display and manage your PDFs, the App stores the following information only on your device:

  • The library (recently opened and pinned PDFs): file name, file size, a reference to the file's location, when it was opened, etc.
  • Bookmarks
  • Copies of PDFs shared from other apps, and temporary copies of PDFs used to speed up display

Annotations such as highlights, handwriting and sticky notes, as well as page reordering and deletion, are written into the PDF file itself (the original file or a location you choose) when you choose to save.

The App does not collect any information that identifies you, such as your name, email address, location, or advertising identifier. Neither the content of your PDFs nor the information above is ever sent to the Developer or anywhere else.

2. Where Data Is Stored / Third-Party Sharing

The App does not perform any internet communication (it does not even hold the internet permission). It contains no advertising SDK, analytics SDK, or crash-reporting SDK.

As a result, your PDFs and your library and bookmark data are never uploaded or transmitted to any server operated by the Developer, and the Developer does not share your information with third parties.

3. Permissions Used

The App does not request permissions such as camera, location, contacts, or broad storage access. Access to a PDF is granted only for the file you choose, through the file picker or sharing features provided by the operating system.

So that a PDF picked in the file picker can be reopened from the library, the App keeps the access grant for that file using the mechanism provided by the operating system. The grant is released when you remove the PDF from the library.

4. Data Deletion

Removing a PDF from the library deletes its library entry, its bookmarks, and any copy stored inside the App (your own original file is not deleted).

Uninstalling the App removes all data stored on the device (except for any copies that may remain in a device backup made by the operating system).

5. Children's Privacy

The App is not directed at children and does not collect personal information from any user, including children.
